# 常见问题（FAQ）

## 识别相关

**Q：点击识别/匹配后报 "InsightFace model pack not found"？**

模型包尚未下载。执行 `python scripts/download_models.py` 完成一次性下载后重试。模型缺失只影响识别环节，导入、扫描、审核已有结果、归档、导出均正常可用。

**Q：识别出来的匹配不准？**

在 **Settings** 中调整匹配置信度阈值（`MATCH_THRESHOLD`，范围 0–1）：调低更宽松（召回多、误配多），调高更严格。修改后对下一次匹配生效，历史结果需重新匹配。

## 归档相关

**Q：点归档提示 "ARCHIVE_ROOT is not configured"？**

归档根目录尚未配置。编辑项目根目录的 `.env` 设置 `ARCHIVE_ROOT=<你的归档总目录>` 后重启应用；或在命令行走 `python main.py archive --archive-root <目录>`。

**Q：目标位置已有同名文件怎么办？**

由冲突策略决定（预览对话框中可选）：`skip` 保持现状（默认，最安全）、`overwrite` 覆盖旧文件、`rename` 写成 `x.dup-1.jpg` 这类兄弟文件名。拿不准时可先勾选 **dry-run** 只看计划不动文件。

**Q：为什么有些照片没有出现在归档计划里？**

只有经过人工审核标记为 **approved** 的照片才会归档。请先通过 **Review Pending** 处理待审结果；或在照片列表中确认目标照片已被当前筛选条件包含。

## 数据相关

**Q：重复导入同一份名单会怎样？**

带证件号且号码已存在的人员会计入“跳过”，不会产生重复记录；**未填写证件号的行没有去重依据，每次导入都会新增一条**——正式名单建议务必提供唯一证件号。

**Q：所有数据都存在哪里？如何备份？**

业务数据集中在单文件 SQLite 数据库 `data/photo_archiver.db`（路径可由 `DATABASE_URL` 修改），停止应用后直接拷贝该文件即完成备份。缩略图缓存与导出产物位于输出目录，丢失可重建/重新导出。

## 平台相关

**Q：支持 macOS 吗？**

macOS 是官方目标平台之一，持续集成已在三操作系统矩阵上验证测试套件。桌面运行需本地 Python 3.11 环境；Windows 体验优先。

## 其他

**Q：日志在哪里？**

`logs/photo_archiver.log`，10 MB 自动轮转、保留 30 天。提交问题时请附上最近一段日志（注意先去除其中的隐私路径信息）。

**Q：插件功能怎么用？可以自己写吗？**

它们来自 `examples/plugins/` 的示例扩展（统计报表、演示导入人员、问候），以主界面工具栏动作呈现。加载失败的插件会被自动跳过，不影响主程序。开发自有插件请参阅 [`docs/development/plugin-guide.md`](../development/plugin-guide.md)。
