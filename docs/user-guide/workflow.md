# 核心业务闭环操作指南

主窗口工具栏自左向右对应标准业务的六个环节。推荐首次使用时按顺序体验一遍。

## 流程总览

```text
① 导入人员 → ② 扫描文件夹 → ③ 审核待处理 → ④ 归档
        （检测重复 / 删除登记 / 删除人员 / 导出数据 / 设置 随时可用）
```

## ① 导入人员

点击工具栏 **导入人员**，选择 `.txt` / `.xlsx` / `.xls` 名单文件。

- 每行一位人员：姓名必填；证件号（identity）、部门、备注可选。
- 身份号已存在的人员自动跳过（去重），结果在完成后提示导入/跳过/错误计数。
- 单行错误不会中断整批导入，错误明细写入日志并汇总展示。

## ② 扫描照片

点击 **扫描文件夹** 选择照片目录，程序递归扫描图片并注册入库：

- 自动提取尺寸、拍摄时间（EXIF 优先）等内容元数据；
- 同一文件内容计算 SHA-256 哈希，供后续重复检测；
- 进度实时显示在底部状态栏，完成后照片出现在中央列表。

**重扫对账**：对同一目录再次扫描时，内容发生变化（哈希或修改时间/大小）
的照片会自动刷新其元数据登记（结果计入 `updated` 计数）；未变化的照片保持
原登记不动。拍摄时刻等快照信息不会被重扫覆盖。

## ②·补 照片筛选

照片列表支持按**人员 / 审核状态 / 捕获时间区间**三轴组合筛选；其中人员轴
支持**键入即时搜索**——输入一个字即列出包含该字的人员，多个字按智能相似度
排序（全等 → 前缀 → 连续包含 → 按序子序列）。未选择任何条件 = 显示全部；
点"清除"一键复位。

## ③ 审核识别结果

执行过人脸匹配后，点击 **审核待处理** 打开审核对话框：

- 逐条查看候选匹配，**通过所选**（采纳）或 **拒绝所选**（驳回），也可 **全部通过**；
- 只有 **已通过** 的照片才会进入归档环节；
- 审核即时生效并持久化，可随时关闭稍后继续。

## ④ 归档

点击 **归档** 打开归档预览：

1. 预览对话框列出本次将执行的复制计划（目标路径 = `{ARCHIVE_ROOT}/{人员}/{日期}/{文件名}`）；
2. 可选择冲突策略：**跳过（保留现有文件）**（默认）/ **覆盖同名文件** / **自动重命名**；
3. 勾选 **试运行（仅预览，不写入文件）** 可只生成计划不落盘；
4. 在列表中多选照片可只归档选中项；未选择时归档全部已通过照片。

> 若提示「未配置归档根目录（ARCHIVE_ROOT）」，请在 `.env` 中设置该目录后重启，或改用命令行 `python main.py archive --archive-root <目录>`。

## ⑤ 库管理（删除登记 / 删除人员 / 重复处置）

照片库自 v2.4.0 起支持"只进也出"的长期运营能力。**所有删除只作用于库内
登记，绝不触碰磁盘上的任何文件**；每次删除都需在确认对话框中核对级联计数
预览后才会执行，并写入操作审计日志。误删可从启动自动备份恢复。

### 删除登记（照片）

在照片列表中按住 Ctrl / Shift **多选**照片，点击工具栏 **删除登记**：

1. 确认对话框显示将移除的照片数，以及随之级联移除的识别结果、归档记录数；
2. 确认后登记从库中移除，照片列表即时刷新；
3. 不在库中的所选项自动跳过（幂等，不报错）。

### 删除人员

点击工具栏 **删除人员**，在下拉中选择人员：

- 对话框实时预览：该人员的人脸嵌入将一并删除；其识别结果**保留**但归属
  置空（显示为"未知人员"）；
- **该人员的全部照片与磁盘文件均保留**——人员只是照片的归属维度；
- 确认后人员轴筛选与照片列表即时刷新。

### 重复照片处置

点击 **检测重复** 打开报告后，点 **按建议处置（每组保留最早一张）**：

1. 二次确认显示组数、将移除的登记数与级联计数；
2. 每组保留**最早注册**的一张（同刻按内部标识决胜），其余成员移除登记；
3. 被保留者与未重复的照片绝不会误删（执行端逐项复核）。

### 清理失联登记（命令行）

磁盘文件已丢失的登记不会在扫描时被自动删除（防止移动盘未挂载造成误判）。
使用命令行显式清理：

```text
python main.py prune-missing              # 只列出失联登记（默认 dry-run）
python main.py prune-missing --execute    # 确认后移除这些登记
```

## 附加能力

| 功能 | 说明 |
|---|---|
| **检测重复** | 按内容哈希分组展示重复照片报告，并支持按建议处置（见 ⑤） |
| **导出数据** | 将人员/照片/审核/归档数据导出为 Excel（`.xlsx`）、CSV 或 HTML 报告 |
| **设置**（Ctrl+,） | 调整界面主题、语言、匹配置信度阈值、后台并发数等偏好，保存于系统原生设置存储 |
| **插件扩展** | 插件机制保留为外部扩展点（加载器支持从任意目录加载并渲染到工具栏）；仓库自带示例见 `examples/plugins/`，默认不自动加载，接入方法见 [`docs/development/plugin-guide.md`](../development/plugin-guide.md) |

## 命令行对照

| 图形操作 | 等效命令 |
|---|---|
| 扫描文件夹 | `python main.py scan <目录> [--no-recursive] [--name 显示名]` |
| 归档（全量已通过） | `python main.py archive --archive-root <目录> [--dry-run] [--conflict-strategy ...]` |
| 历史哈希回填 | `python main.py backfill-content-hash` |
| 拍摄时刻回填 | `python main.py backfill-capture-time [--execute]`（默认 dry-run） |
| 清理失联登记 | `python main.py prune-missing [--execute]`（默认 dry-run） |
| 导入人员 | `python main.py import-people <文件> [--no-header] [--sheet-name ...]` |
| 导出数据 | `python main.py export <输出> [--format xlsx/csv/html] [--scope filtered --status ... --person ...]` |
| 缩略图缓存清理 | `python main.py cleanup-thumbnails [--execute]`（默认 dry-run） |
| 旧库迁移 | `python main.py migrate [--execute]`（默认 dry-run；复制不搬移） |
| 捕捉时刻纠错 | `python main.py backfill-capture-time [--execute]` |
